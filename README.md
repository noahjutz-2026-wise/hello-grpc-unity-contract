# Unity + gRPC C# library

https://www.nuget.org/packages/com.noahjutz.hellogrpcunitycontract/

Packages generated protobuf C# messages.

## Quickstart

Pack & Publish:

```bash
dotnet pack -c release
dotnet nuget push HelloGrpcUnityContract/bin/Release/...nupkg \
    --api-key <API-key> \
    --source https://api.nuget.org/v3/index.json
```
